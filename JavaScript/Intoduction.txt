#What is JavaScript?
A Website is built with three core technologies:
1. HTML - Structure / Content 
2. CSS - Styling / Apprearence 
3. JavaScript - Behavior / Interactivity 
# Where itr runs: Originally designed to run in web browsers, JavaScript now also runs on servers(via Node.js),
mobile apps, desktop applications, and even IoT devices.
#Core features: It supports object-oriented, functional, and event-driven programming styles. It's dynamically typed, meaning you don't 
need to declare variable types explicitly.
#The DOM: JavaScript can manipulate the Document Object Model(DOM), allowing it to dynamically change a webpage's content, structure, and styling
in real time without reloading.
#Asynhronous programming: It supports asynhronous operations through callbacks, Promises,  and 'async/await', making it efficient for tasks like 
API calls and file handling.
