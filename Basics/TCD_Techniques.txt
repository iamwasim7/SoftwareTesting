1. What are Test Case Design Techniques?
Definition: Test Case Design Techniques are methods used to create effective test cases to verify software functionality and identify defects.
Simple meaning: They help us decide what to test, which inputs to use, and which conditions to check.
For example, imagine a login page with a username and password. Instead of trying random inputs, we use design techniques to select meaningful test cases.

2. Types of Test Case Design Techniques
There are three main categories:

1. Black Box Testing Techniques
Test without knowing the internal code.
Examples: Equivalence Partitioning, Boundary Value Analysis, Decision Table Testing, State Transition Testing.

2. White Box Testing Techniques
Test based on the internal code and program logic.
Examples: Statement Coverage, Branch Coverage, Condition Coverage, Path Coverage.

3. Experience-Based Testing Techniques
Use tester experience and knowledge to identify potential defects.
Examples: Error Guessing, Exploratory Testing, Checklist-Based Testing.
