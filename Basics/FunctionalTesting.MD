Functional Testing is a type of software testing that checks whether an application's features work according to the specified requirements.

It focuses on what the application does, rather than how well it performs.

Example: In an online shopping website, functional testing checks whether users can log in, search for products, add items to the cart, and place orders correctly.

What do we test in Functional Testing?

Login Testing
Check whether valid credentials allow login and invalid credentials are rejected.

Search Testing
Check whether searching for a product displays relevant results.

Cart Testing
Check whether products are added, removed, and priced correctly.

Checkout Testing
Check whether an order is placed successfully when all required details are correct.

Types of Functional Testing
Common types include:
Type	                     Meaning	                                                Example
Unit Testing	             Tests individual components	                            Testing a function that calculates a discount
Integration Testing	         Tests interactions between components	                    Checking whether checkout sends the correct order details to the payment service
System Testing	             Tests the complete application	                            Testing the entire shopping process
Acceptance Testing (UAT)	 Checks whether the software meets user or business needs	A client verifies that the shopping website meets requirements

These are testing levels commonly associated with functional testing; they can also include non-functional checks.

Advantages
- Verifies that features work correctly.
- Helps identify defects in business logic.
- Ensures the application meets requirements.
- Improves software quality and user satisfaction.
